# Palette explorations

Before component implementation, three paper-based palettes were considered:

| Palette                   | Background | Surface | Text    | Accent  | Accent hover |
| ------------------------- | ---------- | ------- | ------- | ------- | ------------ |
| Terracotta study (chosen) | #f6f3eb    | #fffdf7 | #292b25 | #ac482d | #87351f      |
| Forest library            | #f3f1e7    | #fffdf5 | #25332b | #35634b | #254b37      |
| Amber notebook            | #f7f1e4    | #fffaf0 | #342d22 | #a46312 | #814b0c      |

Terracotta makes the confusion overlay intuitive while retaining a quiet editorial workspace. Lora headings and document text pair with a neutral system sans. Thin rules, numbered sections, visible paper edges, and a dotted work surface replace glossy cards. All core colors live in app/globals.css.
